Project-card PNGs combine original graphic framing with actual application captures from [the portfolio gallery](https://github.com/vmargin/vmargin.github.io/tree/dd7e03f724c08c83154d9dbab8df7d9e302a7194/public/images/projects). CASH-G and ARCTIC show isolated local synthetic-data demos; AssetHub shows its synthetic inventory interface. Image provenance and evidence limits are in [the portfolio record](https://github.com/vmargin/vmargin.github.io/blob/dd7e03f724c08c83154d9dbab8df7d9e302a7194/docs/evidence-sources.md).

Social previews use the same 1280 × 640 composition. The profile avatar is unchanged. The project cards are illustrations of selected work, not evidence of live service availability.
